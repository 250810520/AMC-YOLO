# AMC-YOLO

YOLO11 steel surface defect detection with AIFI, CARAFE and MCA.

Run `python text.py`, `python text-aifi.py`, or `python text-gaijin.py` from a CUDA-enabled Python environment to evaluate the baseline, AIFI and AMC models, respectively. The dataset configuration is in `lv_yolo11.yaml`. Use the bundled modified Ultralytics source.

The supplied evaluation configuration uses settings previously tuned on the test split. Results under this configuration should be reported with that qualification.
